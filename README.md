# Steps to Setting Up the Project

## Step 1: Pull the Repository to Your Local System

Navigate to a suitable location where you would like to download the project repository. Once there, run the command below to download the repository. 

```bash
git clone https://github.com/loridenning70-crypto/SBL_2026.git
```

## Step 2: Navigate to the Repository

Navigate into the repository folder with the below command. If you are not sure what this new folder is named, type 'ls' into the terminal and it will display all the folders in the current directory. 

```bash
cd SBL_2026
cd super-control-panel
```

## Step 3: Install NPM Dependencies

We need all of the special tools which make this project possible! To do so, run the commands below. You will run the development server with the second command, then with the link it provides, you can access the control panel!!!

```bash
npm install
npm run dev
```
